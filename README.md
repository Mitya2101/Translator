# Мини язык программирования

Проект представляет собой реализацию простого языка программирования с собственным интерпретатором и виртуальной машиной.
- лексический анализ (разбиение на токены)
- синтаксический анализ (проверка соотвествия грамматике)
- семантический анализ (проверка соответствия типов и наличия переменных)
- генерацию ПОЛИЗА
- исполнение ПОЛИЗА (с помощью виртуальной машины написанной на C++)

Написан на C++17 без сторонних библиотек

## Пример работы

Примеры программы вычисления GCD(НОД) на данном языке программирования:

```
int gcd(int a,int b){
    if(b == 0){
        return a;
    }
    return gcd(b,a % b);
}

print(gcd(6,4));
```
Вывод: 
2

## Пример вывода ошибки 

Пример некорректной программы:
```
int a = 5;
a = 3.4;
```
Вывод:
Error: You have different types in 2 line and 2. Have double and 0 dimensional, but expected int and 0 dimensional

Другой пример:
```
print(x);
```
Вывод:
Error: x - no such variable

## Функционал языка

На данный момент язык поддерживает: 
- базовые типы данных(int, double, char, bool)
- переменные
- Приведение типов
- арифметические операции
- условные конструкции
- циклы (for, while)
- функции (в том числе рекурсия)
- массивы константных размеров (размером может быть выражение, которое будет вычисляться в compile time)


## Архитектура

Pipeline обработки программы:

```
Исходный код
    ↓
Лексический анализ
    ↓
Синтаксический анализ + Семантический анализ + Генерация ПОЛИЗ
    ↓
Исполнение
```

## Особенности реализации

- используется ПОЛИЗ (обратная польская запись) как промежуточное представление программы
- реализована собственная виртуальная машина для исполнения ПОЛИЗ
- поддерживаются рекурсивные функции
- выполняется статическая проверка типов во время компиляции


## Build

Зависимости: 
- C++17
- CMake
- GCC/Clang

Build:
```bash
git clone https://github.com/Mitya2101/Translator
cd Translator
mkdir build
cmake ..
make
```

Запуск:
```bash
./MyLang program.txt
```

## Тесты

В проекте реализована система автоматических тестов для проверки корректности работы языка.
Каждый тест представляет собой небольшую программу, которая запускается интерпретатором.
Результат выполнения программы сравнивается с ожидаемым выводом.


Запуск тестов:
```bash
ctest
```
или
```bash
ctest -V
```
для большей информативности
