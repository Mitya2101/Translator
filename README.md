# MyLang

Проект: лексер → синтаксер → генерация POLIZ → исполнение (VM).

## Сборка (CMake)

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

## Запуск

По умолчанию берётся `test.txt` (ищется рядом с местом запуска и на 1–2 уровня выше):

```bash
./MyLang
```

Или можно явно указать файл:

```bash
./MyLang path/to/program.txt
```

## Встроенные функции

- `print(a, b, ...)` — печать аргументов через пробел + `\n`
- `read(x)` — ввод значения в переменную

## Примечание

Если определена функция `main`, VM автоматически вызовет её. Иначе выполнит top-level POLIZ (если он есть).
